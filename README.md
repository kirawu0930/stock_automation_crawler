# \# 📈 台灣股市自動化爬蟲 (Taiwan Stock Automation Crawler)

# 

# 這是一個基於 Python 與 Playwright 開發的自動化爬蟲腳本，專門用於擷取 Yahoo 奇摩股市的即時/昨收股價資訊，並自動分類儲存為每日 CSV 報表。

# 

# \## 🌟 功能亮點

# \- \*\*自動化操作\*\*：模擬真實瀏覽器行為，自動處理動態載入網頁。

# \- \*\*資料清洗\*\*：內建 `clean\_numeric` 邏輯，自動移除千分位逗號與空白，確保資料純淨。

# \- \*\*批次擷取\*\*：支援多個股票代碼連續抓取（範例包含 2300-2309）。

# \- \*\*自動存檔\*\*：以日期命名 CSV 檔案（例如：`20231027\_stock\_data.csv`），並自動建立標題列。

# \- \*\*異常處理\*\*：具備 `try-except` 機制，單一股票失敗不影響整體執行。

# 

# \## 🛠️ 技術棧

# \- \*\*語言\*\*: Python 3.8+

# \- \*\*核心庫\*\*: 

# &#x20; - \[Playwright](https://playwright.dev) (網頁自動化)

# &#x20; - \[CSV \& OS](https://python.org) (資料處理與檔案管理)

# \## 📊 輸出範例

# 

# | 時間 | 代碼 | 名稱 | 股價 | 最高 | 最低 |

# | :--- | :--- | :--- | :--- | :--- | :--- |

# | 2023-10-27 14:30:00 | 2330 | 台積電 | 590 | 595 | 588 |

# 

# \## 📝 程式碼結構說明

# \- `get\_stock\_data()`: 負責開啟網頁、定位元素並擷取原始文字。

# \- `clean\_numeric()`: 格式化文字為數字，移除逗號。

# \- `save\_To\_csv()`: 判斷檔案是否存在，執行追加 (Append) 寫入。

# \- `run()`: 控制瀏覽器生命週期與爬取迴圈。
